# Cruisr · cockpit de vente

Outil HTML autonome, un seul fichier, ouvert dans le navigateur pendant les appels.

| Fichier | Qui | Quand |
|---|---|---|
| `cockpit_coldcall_vXX.html` | SDR | Cold call, séquence de relance, courriels |

URL : `https://greg0502-cruisr.github.io/cruisr-sales-cockpit/cockpit_coldcall_v03.html`

## Règles
- Le numéro de version est dans le nom du fichier. On ne modifie pas une version publiée : on dépose la nouvelle, on supprime l'ancienne, on envoie le nouveau lien.
- Le profil et le bloc-notes se sauvegardent dans le navigateur (localStorage), sur cet ordinateur seulement. Le CRM reste la source : « copier → CRM » après chaque appel.
- Les notes de modif s'exportent par « copier les notes » et se collent dans ClickUp. C'est le canal pour améliorer le document.
- Si l'URL de base change un jour, les sauvegardes locales ne suivent pas : exporter les notes avant.

## Utilisation
1. Régler industrie, âge, revenus à droite — le hook et les pains suivent.
2. Naviguer par situation : onglets 1-4, flèches ↑↓.
3. Bloc-notes pendant l'appel, « copier → CRM » après.
4. Un mot qui sonne faux, une objection qui manque : « + note de modif ».
